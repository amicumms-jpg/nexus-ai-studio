# 🚀 Nexus AI Studio Pro

**Nexus AI Studio Pro** is a modern, feature-rich web application designed to bring powerful AI capabilities directly to your browser through a sleek, futuristic interface.

## ✨ Key Features

- **Multi-Model AI Chat**: Seamless interaction with advanced AI assistants.
- **Multilingual Support**: Dynamic language switcher powered by Google Translate integration for global accessibility.
- **Interactive Emoji Picker**: Fully integrated custom emoji picker right inside the chat input field for expressive conversations.
- **Session Management**: Easily export chat sessions and manage quick notes on the fly.
- **Cyberpunk / Futuristic UI**: Built with Tailwind CSS, custom glassmorphism effects, and immersive themes.
